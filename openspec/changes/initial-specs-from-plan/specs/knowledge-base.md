# Knowledge Base и RAG

## Overview
Агент опирается на знания из whitepaper "AI-Disrupt PDLC" и со временем будет обогащаться внутренними кейсами организации.

## Requirements

### KB-1. Основной источник
- Полноценный RAG по полному тексту белой книги.
- Чанки должны иметь богатые метаданные:
  - Часть книги
  - Принцип (из 4 архитектурных)
  - Уровень зрелости (L0-L5, R0-R5)
  - Тип: принцип, паттерн, антипаттерн, метрика, пример, gate-критерий

### KB-2. Строгое grounding
- Агент обязан ссылаться на книгу при важных утверждениях.
- При отсутствии информации в книге — явно говорить об этом.
- Запрещено придумывать принципы или уровни.

### KB-3. Внутренние материалы (будущее)
- Поддержка отдельной коллекции для внутренних кейсов, антипаттернов и практик организации.
- Чёткое разделение: "По книге" vs "По нашим кейсам".
- Внутренние материалы не должны противоречить основным принципам книги.

### KB-4. Инструменты поиска
- Семантический поиск по принципам и уровням.
- Возможность запросить конкретный раздел/принцип.

## Acceptance Criteria
- При генерации диагностики или рекомендаций агент может привести цитату или ссылку на соответствующий раздел книги.
- При добавлении внутренних знаний старые ответы по книге остаются корректными.

## Non-Goals
- Полная замена чтения белой книги командой.
