# Сценарии работы Disrupt PDLC Coach

## Overview
Агент должен уметь вести пользователя по полным end-to-end сценариям, а не просто отвечать на разрозненные вопросы. Каждый сценарий заканчивается полезным артефактом и может быть продолжен позже.

## Requirements

### SR-1. Диагностика зрелости команды
- Проводит структурированную оценку по L0–L5 (организационная зрелость).
- Оценивает R0–R5 (уровень автономии агентов).
- Учитывает медианный горизонт задач (task horizon).
- Выдаёт отчёт с:
  - Текущим уровнем и обоснованием.
  - Сильными и слабыми сторонами.
  - Рекомендациями по следующим шагам.
  - Ссылками на gate-критерии перехода.
- Сохраняет результат в профиль команды.

**Acceptance Criteria:**
- Диагностика использует точные профили уровней из книги.
- Отчёт содержит измеримые признаки (например, "Есть AI-gate в CI?", "Используется Evidence Bundle?").
- Агент предупреждает о типичных ошибках смешения осей (L, R, task horizon).

### SR-2. Построение Roadmap трансформации
- На основании диагностики (или ручного ввода) строит реалистичный план движения к целевому уровню.
- Учитывает рекомендуемые временные горизонты из книги:
  - L0→L1: дни
  - L1→L2: 1–3 месяца
  - L2→L3: 6–12 месяцев
  - L3→L4: 12–18 месяцев
- Каждый этап включает:
  - Ключевые практики для внедрения.
  - Gate-критерии.
  - Риски и антипаттерны.
- Выдаёт roadmap в удобном для команды формате.

### SR-3. Проектирование элементов
Поддерживает проектирование следующих элементов (минимум):
- Среда работы агентов (harness)
- Guardian Agents (архитектура и уровни зрелости)
- Контур управления (Governance Mesh)
- Роли в ИИ-нативной команде
- Методика валидации и Evidence Bundle
- Процесс Discovery

Выход: Спецификация элемента + рекомендации по внедрению + чек-лист.

### SR-4. Аудит практик
- Принимает описание текущих процессов/практик.
- Проверяет на соответствие принципам книги.
- Выявляет антипаттерны.
- Даёт конкретные рекомендации по улучшению.

### SR-5. Сопровождение трансформации
- Позволяет обновлять статус по roadmap.
- Проверяет прогресс по gate-критериям.
- Корректирует план при необходимости.
- Фиксирует регулярные сессии (чек-поинты).

## Non-Goals
- Автоматическое выполнение задач за команду.
- Замена всех встреч с живым коучем.
