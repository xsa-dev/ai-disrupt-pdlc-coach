# Proposal: Share current stage and its required steps (methodologies)

## Why
Страница `methodologies.html` — фильтруемый каталог методик по этапам жизненного
цикла (Discovery → Specification → Execution → Validation → Outcome → Governance).
Пользователь, находясь на конкретном этапе, хочет **поделиться**: «я сейчас на
этапе X, вот необходимые шаги» — чтобы отправить коллеге ссылку и чек-лист.

Сейчас такой возможности нет: выбранный этап не отражается в URL (deep-link
невозможен), и нет кнопки «Поделиться».

## What Changes
Добавить на `methodologies.html` возможность делиться текущим этапом и его шагами.

1. **Deep-link состояния этапа.** Выбранный этап SHALL отражаться в URL как
   `?stage=<StageName>`; при загрузке страницы фильтр SHALL восстанавливаться
   из этого параметра (напр. `?stage=Specification` открывает страницу с уже
   выбранным этапом Specification).
2. **Кнопка «Поделиться».** Рядом с фильтром этапов SHALL быть кнопка, которая
   формирует шар: **ссылку** (deep-link на текущий этап) + **текстовую выжимку**
   (название этапа + для каждой методики этапа её название и её `steps` —
   полный чек-лист шагов всех методик этапа).
3. **Механизм шеринга.** Кнопка SHALL использовать Web Share API
   (`navigator.share`) на устройствах, где он доступен (нативное меню на
   мобильных / in-app браузерах Threads/Telegram); при отсутствии — fallback на
   copy-to-clipboard с видимым подтверждением.

### Пример шара (этап Specification)
```
Этап OpenSpec: Specification
Ссылка: https://xsa-dev.github.io/ai-disrupt-pdlc-coach/methodologies.html?stage=Specification

Необходимые шаги:
• Дельта-спецификация
  1. Описать разницу как ADDED/MODIFIED/REMOVED
  2. …
• …
```

## Scope
Только `web/methodologies.html` (client-side JS + разметка кнопки). Реестр
методик (`methodologies-data`) уже содержит поле `steps` — источник шагов.
Без бэкенда, без новых внешних зависимостей.

## Non-Goals
- Не меняем структуру реестра методик.
- Не шарим при `stage=all` развёрнутый чек-лист по всем этапам (для `all` — только
  ссылка + подсказка выбрать этап); полный чек-лист — для конкретного этапа.
- Не трогаем фильтр по виду (kind) в объёме шара — чек-лист берётся по этапу
  целиком, независимо от фильтра вида.

## Verification
- `?stage=Execution` при загрузке восстанавливает фильтр Execution.
- Смена этапа обновляет `?stage=` в URL (history.replaceState).
- Кнопка «Поделиться» формирует ссылку + чек-лист шагов всех методик этапа.
- Web Share API вызывается там, где доступен; иначе clipboard + подтверждение.
- `openspec validate methodologies-stage-share`.
