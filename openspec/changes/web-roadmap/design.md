# Design - Web Roadmap Page

## High-level Structure

### Основные экраны / состояния страницы
1. **Selector / Input**
   - Заголовок "Построение Roadmap трансформации"
   - Блок "Текущий уровень" (select или карточки L0-L5)
   - Блок "Целевой уровень" (только уровни выше текущего)
   - Кнопка "Сгенерировать Roadmap"
   - Опционально: "Загрузить из диагностики" (если пришли с параметрами)

2. **Roadmap View**
   - Краткая сводка: Current (L2) → Target (L4)
   - Визуальная timeline / последовательность этапов
   - Для каждого этапа:
     - Название перехода (L2 → L3)
     - Ориентировочная длительность
     - Ключевые практики (список)
     - Gate-критерий перехода
     - Риски и антипаттерны
   - Общая оценка времени трансформации
   - Кнопки экспорта

3. **Footer**
   - Ссылка на белую книгу
   - "На основе AI-Disrupt PDLC"

## Visual Design (согласовать с diagnosis.html)
- Тот же Tailwind + цвета (indigo + emerald для roadmap)
- Карточки с мягкими границами
- Для этапов использовать нумерованные блоки или вертикальную timeline
- Цветовое кодирование по уровням (можно лёгкие оттенки)

## Data Model (в JS)

```js
{
  currentLevel: 2,
  targetLevel: 4,
  stages: [
    {
      from: 2,
      to: 3,
      duration: "6–12 месяцев",
      practices: ["...", "..."],
      gate: "...",
      risks: ["...", "..."]
    },
    ...
  ]
}
```

Данные для практик, gates и рисков берутся из:
- levels.js (или вынести общий levels data)
- Дополнительная таблица переходов (hardcoded в JS на первой версии)

## Интеграция с Diagnosis
- Переход по ссылке: `roadmap.html?currentL=2`
- Автоматически выбирает current level и предлагает разумный target (current + 1 или +2)
- Кнопка "Начать с этих уровней" на странице diagnosis после отчёта

## Поведение
- Всё клиентское (чистый JS)
- Можно открыть страницу напрямую
- При экспорте — чистый, удобочитаемый вид

## Будущие улучшения (не в этом change)
- Drag & drop для изменения порядка практик
- Добавление своих практик
- Сохранение roadmap
- Генерация на основе реального RAG по книге
