# Proposal: Course Access Gamification (Behavioral Gate)

## Why
Курс OpenSpec — глубокий контент, не для случайных посетителей. Хотим, чтобы
его открывали **только заинтересованные**: те, кто реально изучал раздел
OpenSpec на сайте и проявил интерес. Это повышает вовлечённость и качество
аудитории курса.

Механика (выбрана пользователем): **behavioral gate**. Курс скрыт. Открывается
только если пользователь:
1. провёл ≥ N секунд на разделе OpenSpec (`openspec.html`), И
2. кликнул кнопку «Мне интересно» (interest-сигнал).

После выполнения — доступ сохраняется в `localStorage` (`courseAccess=unlocked`)
и переход в курс сопровождается **анимацией разблокировки** (геймификация).

## What Changes
- На `openspec.html` добавить кнопку «Мне интересно» и скрытый/затемнённый
  вход в курс (locked-state) до выполнения gate.
- JS-логика: таймер пребывания на странице + обработчик «интересно» →
  при обоих условиях → `localStorage.courseAccess=unlocked` + показать
  анимацию разблокировки → активировать ссылку на курс.
- На `course-openspec.html` при загрузке: если `courseAccess!=unlocked` —
  показать лёгкий «заблокирован»-экран с CTA «Вернуться к разделу OpenSpec».
- Retention-бонус: возврат в курс после разблокировки даёт приветственную
  анимацию (доп. геймификация).

## Scope
Только логика gate + UI-состояния (locked/unlocked) + анимации. Контент курса
не меняется (это отдельный change `course-rewrite`).

## Non-Goals
- Не меняем тексты/модули курса.
- Не делаем серверную авторизацию (только localStorage, client-side).
- Не делаем лидерборды/очки (только gate + разблокировка).

## Verification
- Чистый профиль (нет localStorage): на `openspec.html` курс locked; после
  ≥ N сек + «интересно» → unlocked + анимация; переход в курс работает.
- После разблокировки `localStorage.courseAccess=unlocked` сохраняется.
- `course-openspec.html` без доступа → экран «заблокировано» + CTA.
- Работает в Telegram/Threads in-app WebView (localStorage доступен).
