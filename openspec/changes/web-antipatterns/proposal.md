# Web Antipatterns Section

## Summary
Добавить отдельную страницу `web/antipatterns.html` — учебный раздел «Антипаттерны трансформации» по методологии AI-Disrupt PDLC. Раздел работает как **curriculum к успеху**: собирает все антипаттерны из книги, объясняет что НЕ делать и что делать вместо, и даёт интерактивную викторину для закрепления знаний (К ВИЗ).

## Motivation
- Пользователь хочет вынести все антипаттерны из книги в отдельный раздел сайта. Сейчас они разбросаны (блок «Риски и антипаттерны» в roadmap.html + раздел 7.4 белой книги).
- Принцип «Честная оценка зрелости важнее завышения» предполагает явное обучение команд тому, чего избегать.
- Викторина закрепляет материал: два режима — случайный билет и фиксированные билеты по 10 вопросов, у каждого билета свой стабильный состав.

## Goals
- Страница `antipatterns.html` в едином стиле сайта (emerald / Tailwind через CDN / Font Awesome).
- **Секция 1 — «Частые в первый год»**: 7 подробных антипаттернов из раздела 7.4 (признак раннего предупреждения → структурный фикс → горизонт проявления + блок «что делать вместо»).
- **Секция 2 — «Полный реестр»**: все 22 антипаттерна (базовые №1–18 + управление №19–22) компактными карточками с фильтром по типу (базовый / управление).
- **Секция 3 — КВИЗ «К ВИЗ»**:
  - Режим «Случайный»: 10 вопросов из перемешанного пула (~58 вопросов), уникальный seed-билет.
  - Режим «По билетам»: фиксированные группы по 10 (Билет 1 = вопр.1–10, Билет 2 = 11–20, …), каждый билет стабилен между сессиями.
  - Фидбек после каждого ответа (верно/неверно + почему) и итоговый счёт в конце.
- Пункт меню «Антипаттерны» добавляется в `diagnosis.html` и `roadmap.html`.

## Non-Goals (для этого change)
- Backend / сохранение результатов квиза на сервере.
- Telegram-интеграция квиза.
- Перевод всей книги (берём только антипаттерны: раздел 7.4 + 7 подробных из основного текста).
- Генерация вопросов через LLM (данные hardcoded из книги).

## Scope
- Новая страница: `web/antipatterns.html`
- Правка меню в `web/diagnosis.html` и `web/roadmap.html`
- Данные антипаттернов: hardcoded в JS на основе раздела 7.4 белой книги

## Out of Scope
- Мультикомандность и профили на этой странице.
- Адаптивные лестницы сложности квиза (пока фиксированный размер билета = 10).

## Success Metrics
- Страница отдаётся через Cloudflare-туннель (curl публичного URL → HTTP 200, корректный `<title>`).
- Присутствуют все 22 + 7 антипаттернов (29 описаний).
- Квиз корректно формирует билеты обоих режимов; счёт совпадает с числом верных ответов.
- Навигация между тремя страницами работает в обе стороны.
