# Proposal: Course Content Rewrite for Clarity

## Why
Интерактивный курс OpenSpec (`course-openspec.html`, 8 модулей) написан
плотно и местами с жаргонизмами. Пользователь хочет **более ясное понимание
и качественный контент**: переписать язык проще (без сленга), сохранить
структуру 8 модулей, и добавить **иллюстрации/схемы между модулями** для
наглядности.

Решение (выбрано пользователем): структура 8 модулей остаётся, язык —
проще и понятнее, между модулями — схемы/иллюстрации (inline SVG или CSS-схемы,
без внешних ассетов, чтобы работало в in-app браузерах и офлайн).

## What Changes
- Переписать тексты всех 8 модулей: убрать жаргонизмы, короче фразы,
  конкретные примеры вместо абстракций.
- Добавить между модулями визуальные схемы (жизненный цикл OpenSpec,
  структура delta-спеки, поток «идея → архив») — inline SVG/CSS.
- Сохранить интерактив (квизы, чат из существующей `web-course-ui`),
  но адаптировать формулировки под новый язык.
- Оставить технические термины OpenSpec литералами (`/opsx:explore`,
  `SHALL`, `ADDED/MODIFIED/REMOVED`, `openspec/specs/`, `openspec/changes/`).

## Scope
Только контент/тексты модулей + схемы. UI-каркас курса (навигация, квизы,
гейт) — в других changes (`web-course-ui`, `course-gamification`,
`web-mobile-inapp`).

## Non-Goals
- Не меняем структуру 8 модулей (остаётся).
- Не меняем интерактивную логику (квизы/чат) — только тексты подсказок.
- Не добавляем новые модули.

## Verification
- Все 8 модулей переписаны, читаются без сленга.
- Между модулями — минимум 1 схема (inline SVG/CSS).
- `openspec validate course-rewrite` проходит.
- Рендер в in-app браузере (схемы не ломаются, нет внешних зависимостей).
