# Proposal: Course footer with second subscribe form + repo links (course-footer-subscribe)

## Why
Пользователь заметил: CTA «Понравился курс?» оказался не в самом низу страницы
(он стоит в модуле 6, перед `back-link`), а в самом низу курса нет ни футера,
ни формы подписки — страница обрывается. Предложено: оставить первую форму
подписки после модуля 6, и добавить **футер в самый низ** (после модуля 8) с
повторной формой подписки + ссылками на официальный репозиторий OpenSpec и репо
сайта.

## What Changes
- `web/course-openspec.html`: добавить блок `.course-footer` в конец (после
  модуля 8, перед закрывающим `</section>`):
  - вторая форма подписки (кнопка открывает модалку с проставленным чекбоксом);
  - ссылки: официальный репо OpenSpec (https://github.com/Fission-AI/openspec),
    репо сайта (https://github.com/xsa-dev/ai-disrupt-pdlc-coach);
  - навигация «← Вернуться к разделу OpenSpec» (перенести сюда из модуля 6).
- Убрать `back-link` из модуля 6 (остаётся только CTA подписки там).
- Добавить CSS для `.course-footer` в инлайн-`<style>`.

## Impact
- Только фронтенд курса. Нет бэкенда, `publish-policy.json` не меняется.
- Риск: минимальный.
