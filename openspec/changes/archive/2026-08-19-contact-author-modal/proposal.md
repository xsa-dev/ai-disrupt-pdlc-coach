## Why

Сайт опубликован публично (https://xsa-dev.github.io/ai-disrupt-pdlc-coach/), но у посетителя нет встроенного способа связаться с автором прямо из интерфейса. Контакты сейчас существуют только в тексте TG-поста; на самом сайте их нет. Это снижает обратную связь по Quiz, диагностике и roadmap — а именно её автор явно запросил («Буду рад обратной связи»).

Нужен единый, доступный на всех страницах механизм: всплывающее окно «Связь с автором» с контактами (Telegram, GitHub, email) и формой отправки сообщения без необходимости покидать сайт.

## What Changes

- Добавить на все 5 страниц сайта (`index.html`, `diagnosis.html`, `antipatterns.html`, `methodologies.html`, `roadmap.html`) фиксированную кнопку-триггер «Связь с автором» и подгружаемый модальный компонент контактов.
- Модалка содержит:
  - блок контактов — Telegram `@alxy_tg`, GitHub `xsa-dev`, email `saleksey67@gmail.com`;
  - текстовое поле сообщения с кнопкой «Отправить».
- Способ отправки (без бэкенда, сайт статичный):
  - **По умолчанию:** `mailto:saleksey67@gmail.com?subject=...&body=...` — открывает почтовый клиент с предзаполненным письмом (работает офлайн, zero external deps).
  - **Опционально:** если у элемента задан `data-contact-endpoint`, сообщение POST-ится по этому URL (например Formspree) — без секретов в репо, endpoint публичный.
- Доступность: ESC и клик по оверлею закрывают модалку; focus-trap; `role="dialog"` + `aria-modal="true"`; триггер доступен с клавиатуры.

## Impact

- Новых runtime-зависимостей от внешних CDN нет (только нативный `mailto:` и опц. внешний POST-endpoint по выбору).
- Не меняет существующую логику страниц, кроме добавления 1 скрипта + 1 стиля и кнопки-триггера.
- Все страницы остаются статичными и деплоятся через существующий GitHub Pages workflow; **требуется обновить `publish-policy.json` `allowed_web_files`** (добавить `web/contact-modal.css` и `web/contact-modal.js`), иначе artifact-гейт заблокирует деплой.
- Сообщения без endpoint уходят через почтовый клиент пользователя на `saleksey67@gmail.com`.
