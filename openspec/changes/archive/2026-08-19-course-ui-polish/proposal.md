# Proposal: Course UI Polish (course-ui-polish)

## Why
После публикации интерактивного курса по OpenSpec (PR #2) получены два
пользовательских предложения по улучшению UX курса и раздела OpenSpec:

1. **CTA-блок «Хочешь понять OpenSpec на практике?»** сейчас лежит внизу
   страницы `openspec.html` (после теоретических выжимок). Пользователь
   хочет видеть его **наверху**, сразу под навигацией и перед заголовком
   «Разработка через OpenSpec», чтобы вход в курс был заметен сразу.
2. **Курс визуально выбивается из сайта.** `course-openspec.html` грузит
   дизайн-систему скилла `codebase-to-course` (тёплая палитра, vermillion
   `#D94F30` акцент, шрифты Bricolage Grotesque / DM Sans). Основной сайт —
   Tailwind с `emerald` (изумрудно-зелёный) акцентом, slate-текстом и
   системными шрифтами. Курс выглядит «чужим». Нужно привести его к
   палитре и стилистике сайта.

## What Changes
- `web/openspec.html`: переместить CTA-блок про курс из конца `<main>` в
  начало (сразу после открытия `<main>`, перед `<h1>`).
- `web/course-openspec.html`: переопределить CSS custom properties
  дизайн-системы скилла (`:root` в инлайн-`<style>`) на палитру сайта —
  emerald акцент (`#059669`/`#047857`), slate текст/бордеры, системные
  шрифты, светло-зелёный фон hero. Сам `styles.css` скилла не правим
  (только переопределяем переменные, чтобы не дублировать движок).

## Impact
- Только фронтенд-страницы сайта. Нет бэкенда, нет новых зависимостей.
- Никаких изменений в `publish-policy.json` (файлы те же).
- Риск: минимальный (только CSS-переменные + перестановка блока).
