# Fix Quiz Logic

## Problem
При симуляции квиза (Node, полный билет) выявлен баг: в ~3 из 10 вопросов билета
массив вариантов ответов `pool` содержит **дубликаты** (один и тот же текст
встречается дважды). Причина — генерация пула
`shuffle(ALL.slice()).slice(0,3).concat(correct)`: правильный ответ может попасть
в первые 3 случайных дистрактора, и тогда в пуле оказывается два одинаковых
варианта, а один дистрактор вытеснен. Пользователь видит повторяющийся ответ —
выглядит как «некорректная логика квиза».

Счёт и навигация (Далее / результат) при симуляции работают корректно (10/10 при
всех верных ответах). Баг — именно в уникальности вариантов.

## Requirements
### Must
- Каждый вопрос квиза имеет ровно 4 **уникальных** варианта ответа.
- Правильный ответ гарантированно присутствует ровно 1 раз.
- Дистракторы не совпадают с правильным ответом и не повторяются между собой.
- Порядок вариантов случайный (правильный не на фиксированной позиции).

### Should
- Дистракторы для type='name' берутся из NAME-пула без правильного термина.
- Дистракторы для type='fix' берутся из FIX-пула без правильного фикса.

## Approach
Переписать генерацию `pool` в блоке QUIZ GENERATION:
```
const distractors = shuffle(ALL.filter(x => x !== a.correct));
pool = shuffle(distractors.slice(0,3).concat(a.correct));
```
где ALL = (type name) ? ALL_NAMES : ALL_FIXES. Это гарантирует уникальность и
отсутствие дубля правильного ответа.
