# Quiz Progress — localStorage + Thin Line

## Problem
Прогресс прохождения билетов не сохраняется: при перезагрузке страницы пользователь
не видит, какие билеты уже проходил и какие — «отлично». Нет стимула доводить билеты
до 100%.

## Requirements
### Must
- Сохранять в `localStorage` под ключом `aipdlc.quiz.progress.v1` факт успешного прохождения
  каждого билета: режим (`random`/`fixed:<n>`), счёт, дату.
- «Отлично пройденным» считать билет с результатом **≥ 80%** (Вариант Б, совпадает с
  текстом результата «Отлично — ты видишь насквозь»).
- В экране выбора билета (`#quiz-setup`) выводить тонкую линию прогресса по отлично
  пройденным **фиксированным** билетам: `Отлично: X / 7` + тонкий зелёный бар.
- При повторном прохождении того же билета — обновлять запись (оставляем лучший результат).
- Быть устойчивым к отсутствию localStorage (приватный режим) — не падать.

### Should
- В экране результата (`#quiz-result`) показывать статус билета: «Впервые пройдено»,
  «Повторно: результат улучшен/сохранён», «Отлично! Билет зачтён».
- Случайный билет тоже сохраняется (под ключом `random`), но в тонкую линию НЕ входит
  (линия — только по фиксированным 1..7).

## Non-Goals
- Нет серверной синхронизации, нет аккаунтов.
- Нет экспорта/сброса прогресса в UI (можно добавить позже).

## Design (SDD)
### PR/FAQ
- **Press Release.** Теперь квиз запоминает твои билеты: пройди фиксированный билет на
  отлично (≥80%) — и тонкая зелёная линия в выборе билета растёт. Открыл снова — прогресс на месте.
- **FAQ.** *Где хранится?* Только в браузере (localStorage), привязано к устройству/браузеру.
  *Что значит «отлично»?* 8/10 и больше. *Сбрасывается ли при рестарте туннеля?* Нет, это
  браузерное хранилище, не зависит от сервера.

### Data Model
```js
// localStorage["aipdlc.quiz.progress.v1"] = JSON
{
  "done": {
    "fixed:1":  { score: 10, total: 10, pct: 100, at: 1690000000000 },
    "random":   { score: 8,  total: 10, pct: 80,  at: 1690000000001 }
  },
  "excellent": ["fixed:1"]   // subset of done where pct >= 80
}
```
- Ключ билета: `fixed:<n>` для фиксированных (n от 1), `random` для случайного.
- Кол-во фиксированных билетов = `Math.ceil(QUIZ.length / TICKET_SIZE)` (сейчас 7).

### Functions
- `loadProgress()` → объект (защищённый parse, возвращает `{done:{}, excellent:[]}` при ошибке).
- `saveProgress(p)` → `JSON.stringify` в localStorage (обёрнут в try/catch).
- `recordResult(ticketKey, score, total)` → обновляет `done[ticketKey]` (лучший pct),
  пересчитывает `excellent`, сохраняет, возвращает `{ isFirst, improved, isExcellent, prevBest }`.
- `ticketKeyOf()` → строка ключа текущего билета (из `mode` и `runEl.dataset.label` / выбора).
- `renderProgressLine()` → рисует `Отлично: X / 7` + тонкий бар в `#quiz-progress-line`
  (вставляется в `#quiz-setup`).

### Edge Cases
- `localStorage` недоступен (throw) → `loadProgress` возвращает пустой, `saveProgress` mute.
- Повторное прохождение хуже результата → `done` НЕ ухудшается (храним лучший), `improved=false`.
- Повторное прохождение лучше → `improved=true`, `excellent` пересчитывается.

### UX
- Тонкая линия: контейнер `h-1` (4px) с `bg-slate-800`, внутри `bg-emerald-500` шириной
  `pct%`; подпись `text-xs text-slate-400`.
- Блок результата получает строку статуса `#quiz-result-status` (под detail).

## Success Criteria
- [ ] Прохождение фиксированного билета на ≥80% добавляет его в `excellent`, линия растёт.
- [ ] Перезагрузка страницы сохраняет прогресс (читается из localStorage).
- [ ] Повторное прохождение хуже — не ухудшает запись.
- [ ] Без localStorage — страница не падает, просто без сохранения.
