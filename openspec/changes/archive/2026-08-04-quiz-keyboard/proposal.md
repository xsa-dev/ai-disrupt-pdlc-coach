# Quiz Keyboard Support

## Problem
Квиз управляется только мышью. Нет клавиатурной навигации — неудобно проходить
билеты, особенно в полноэкранном режиме.

## Requirements
### Must
- Цифры `1`–`N` (N = число вариантов, обычно 4) выбирают соответствующий вариант
  ответа и сразу оценивают его (как клик мышью).
- `Enter` на экране выбора режима (setup) запускает квиз в текущем режиме.
- `Enter` во время вопроса (после того, как ответ выбран) переводит к следующему
  вопросу / к результату.
- `Enter` на экране результата перезапускает квиз **в том же режиме**
  (random — новый случайный билет; fixed — тот же номер билета).
- `R` перезапускает квиз в том же режиме (на экране результата и после ответа).

### Should
- Подсказка с клавишами отображается под кнопкой «Начать».
- При нажатии управляющих клавиш в квизе вызывается `preventDefault`, чтобы
  страница не прокручивалась (цифры/Enter/Space).
- Клавиши игнорируются, когда фокус находится в `<select>` / `<input>` / `<textarea>`
  (не ломают выбор номера билета).
- `Esc` выходит из полноэкранного режима (нативно через fullscreenchange).

## Approach
- Вынести логику старта квиза в функцию `startQuiz()` (использует текущий `mode`),
  привязать к клику `quiz-start` и к клавишам.
- Добавить один `document.addEventListener('keydown', ...)`, который по видимому
  блоку (setup / run / result) и состоянию `answered` диспетчеризует:
  - run + !answered + цифра → `opts[n-1].click()`
  - Enter → start / next / restart в зависимости от контекста
  - `r`/`R` → restart
- Добавить `<p>` с подсказкой в `#quiz-setup`.
